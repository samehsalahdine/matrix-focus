# Matrix & Focus

Home-screen app: Eisenhower matrix, habits, pomodoro.

## Clone

```bash
gh repo clone samehsalahdine/matrix-focus
```

or

```bash
git clone https://github.com/samehsalahdine/matrix-focus.git
```

## Put it on the iPhone home screen

1. Enable GitHub Pages: repo **Settings → Pages → Deploy from branch `main` / root**.
2. Open `https://samehsalahdine.github.io/matrix-focus/` in **Safari**.
3. Share → **Add to Home Screen**.

Until Pages is on, drop `index.html` on https://app.netlify.com/drop and use that link in Safari.

`index.html` is the full app. Add it in this repo as `index.html` (same file as Matrix-Focus.html from the chat).
